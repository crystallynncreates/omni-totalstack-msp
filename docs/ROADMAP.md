# Roadmap

## v1.1
- Two-way Supabase sync for every collection (replace localStorage persistence).
- Real-time site status via Supabase Realtime and UniFi webhooks. SMS or Teams alert when a site goes down.
- QuickBooks: push invoices and payments; pull vendor bills automatically.
- Recurring invoice auto-generation plus Stripe off-session auto-pay charges.

## v1.2
- PSA imports (HaloPSA, ConnectWise, Autotask) and IT Glue / Hudu document import.
- Client e-signature on RFS (DocuSign / PandaDoc).
- Mobile tech app (PWA) with QR scanning into tickets.

## v2
- Marketplace activation for the remaining 100+ adapters.
- White-label client portal per MSP (custom domain).
- SaaS billing for Omni tiers (Stripe Billing): Free Forever, Unlimited, Business, Enterprise.
